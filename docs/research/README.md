# 數據、模擬與驗證

這裡說明教學工具使用哪些人體與動作資料、如何估計姿勢和受力，以及目前比對到什麼程度。畫面中的關節力矩是簡化物理模型的結果；肌肉活化是模型分配值，不能當作個人的肌電量測。

- **數據從哪來：**節段質量與質心採用 de Leva 的男女資料，身材比例以 ANSUR II 公開逐人測量建立代理分布；肌肉參數參考公開肌骨模型與量測研究，器械尺寸則混合原廠規格、研究條件和明列的估計。來源與連結見[參考資料](references.md)，具體數值見[肌肉參數](muscle-params.md)與[器械資料](machine-data.md)。
- **模型怎麼算：**先求單側三維姿勢，再由外力及身體節段重量計算關節力矩，最後求符合力矩需求的肌肉分配。計算方式、身體參數與資料核對規則見[方法](methods.md)。
- **怎麼驗證：**用清單軌跡、回歸數值與文獻方向檢查模型，再把深蹲、硬舉與臥推的特定事件和研究數值比對；固定示範身體與依研究條件抽出的虛擬群體分別判定。完整條件與準則見[方法](methods.md)。
- **目前結果：**預設身體 63 項清單軌跡與回歸基準一致；58 條文獻趨勢中 50 條通過。深蹲可比較項固定／群體通過 13/14／8/14（兩筆腰背定義不一致已移出分母）；硬舉類可比較項固定／群體通過 19/28／13/28；臥推（Mausehund 2022、Larsen 2021）可比較項固定 8/33、群體 7/27（Larsen 未報身高，不做群體；Schütz 2022 全為探索性）。逐項差距及研究條件見[深蹲結果](results/squat.md)、[硬舉結果](results/deadlift.md)與[臥推結果](results/bench.md)。
- **主要限制：**模型是準靜態、左右對稱；姿勢策略和器材尺寸不會完整隨個人調整。部分肌肉與器械數值仍是估計，研究的量測定義與模擬條件也未完全相同。見[限制與已知問題](limitations.md)。
- **肩帶已知問題診斷：**30 項與肩帶相關的合理性已知問題的主因分類、單因素敏感度與建議修正順序見[肩帶問題總診斷](shoulder-issues-diagnosis.md)（重現：`node tools/diagnose-shoulder-issues.mjs`）。
- **技術原則：**[健美式技術原則（教練已審閱）](technique-principles.md)。
- **預設動作稽核：**依可量化原則掃描 63 項、各 21 點；逐項狀態及人工複查原因見[技術稽核結果](results/technique-audit.md)。

可重算的研究條件及輸出留在專案根目錄的 [`validation/`](../../validation/)；這裡的文字只呈現目前採用的方法與結果。
