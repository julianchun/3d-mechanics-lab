# 姿勢隨骨長改變：診斷、文獻與設計方案（T40 階段 1）

> 狀態：教練 2026-11-28 決定採方案 A（λ = 1）加選用的個人踝背屈上限，已於 0.12.0 實作；本頁保留為診斷與選案紀錄，以下現況描述（「現行」）指 0.11.1。

本頁只做診斷與方案評估，**沒有修改 `src/biomech.js`**；`node tests/regress.mjs` 維持 IDENTICAL。診斷由 [`tools/diagnose-anatomy-posture.mjs`](../../tools/diagnose-anatomy-posture.mjs) 重現，方案原型由 [`tools/prototype-anatomy-posture.mjs`](../../tools/prototype-anatomy-posture.mjs) 重現（後者把 `src/` 複製到暫存目錄再加補丁，不碰產品檔）。測試組研究的數值**沒有**用來設定或挑選任何方案參數；測試組只出現在「預期影響」一節，且僅為事後報告。

## 1. 摘要

- 現行深蹲／高腳杯的**小腿前傾角完全不隨骨長改變**（`freeSquatShankAngle` 只看 dom、站距、行程 e），身材差異全部由**軀幹前傾**吸收：大腿 +1／−1 SD 使高槓底點軀幹 +4.3／−4.0°，大腿長＋軀幹短＋小腿短的組合比相反組合差 12.5°，小腿角兩者都是 32.8°。
- 髖後移會隨股骨長變，膝前移只隨小腿長變（因為小腿角固定）；系統重心由平衡條件固定。
- 硬舉、早安、RDL 本來就以「槓／腿接觸」或「重心」求小腿角，並非同一個問題；這三者的軀幹角是技術參數（早安、RDL）或由槓位求得（硬舉），不需要這項修改。
- 文獻：直接報告「股骨相對長度對踝背屈與軀幹角」的非測試組研究**很少且證據弱**（Fuglsang 2017 n = 11 對節段比例為**無顯著**；Demers 2018 n = 32 為 r ≈ 0.35–0.45 的相關）。方向（股骨相對長 → 踝背屈較多）有一致的物理與統計支持，**幅度沒有可靠出處**。
- 推薦 **方案 A（以參考身體策略為錨、在平衡約束下分配小腿與軀幹）**，唯一新參數是分配權重 λ（無出處，列為示範假設，需做敏感度）；個人踝背屈上限做成可選輸入，預設不限。預設 1.75 m 男性姿勢逐位元不變。

## 2. 診斷

### 2.1 方法

七個動作（高槓、低槓、前蹲、高腳杯、傳統硬舉、早安、RDL），預設參數，行程最低點 `e = 1`（深蹲大腿對垂直 96.4°）。身體：預設 1.75 m／75 kg 男性；以 ANSUR II 男性逐人資料（`validation/anthropometry/ansur-ii-ratios.json`）的節段比例變異係數（Ls 3.47%、Lt 5.22%、Ltr 5.05%、Lu 3.17%、Lf 3.11%、hipHalf 5.51%、shHalf 4.16%、ankleH 6.87%），把單一節段比例乘 (1 ± CV)（其餘節段與身高不動），另有三組同時變動與兩種等比例大小身材（1.50 m 女 50 kg、2.00 m 男 110 kg）。表中「小腿前傾」＝膝相對踝的前傾角（平底足時即踝背屈）；「膝前移」「髖後移」＝膝／髖相對踝的水平位移；「系統重心」＝身體加槓的重心減足中點（正值偏腳尖）。ANSUR 節段是外觀標記（大轉子、股骨外髁、外踝），不是關節中心，見[方法](methods.md)；此為代理。

### 2.3 什麼隨骨長變、什麼不變，原因

| 量 | 深蹲／高腳杯 | 硬舉 | 早安／RDL |
|---|---|---|---|
| 小腿前傾 | **完全不變**（32.8／30.9／34.7／35.4°）。`squatPose` 與 `gobletPose` 的 `thS` = `freeSquatShankAngle`（dom／站距／行程 e）＋鞋跟項，沒有骨長項。 | 近乎不變（4.9° ± 0.0–0.3）：腿前緣貼槓、槓在足中段，腿長只改變膝高。起槓附近有小幅變化（e = 0.25 時 SD 1.8°）。 | 早安 ±0.7°、RDL ±0.4–1.1°：由重心（早安）或腿不穿槓＋肩在槓上（RDL）求得，但軀幹角與膝角是**輸入**。 |
| 軀幹前傾 | **隨骨長變**：大腿 +1 SD → +4.3°（高槓）、+5.5°（低槓）、+4.2°（前蹲）、+7.5°（高腳杯）；小腿長與軀幹長的影響較小且方向相反（長小腿、長軀幹 → 較直立）。由「系統重心在足中點」的平衡條件解出，是唯一的吸收者。 | 隨骨長變（57.6–67.8°）：由肩胛骨在槓正上方求得。 | **不變**（早安 72.0°、RDL 69.3°）：是教練可調的技術參數（`depth`），不是求解結果。 |
| 髖後移 | 隨股骨長（−23.5／−18.8 cm，±1 SD） | 隨之 | 隨之（髖高變化大，見表） |
| 膝前移 | 只隨小腿長（21.3 → 22.1／20.6 cm）；股骨長無影響 | 3.2–3.5 cm（槓貼腿） | −5.9 至 −8.1 cm（膝在踝後方，因膝角固定） |
| 系統重心 | 固定 +0.8 cm（平衡目標為世界座標 z = 0，足中點 −0.8 cm）；不隨骨長 | −6.3 至 −7.3 cm：硬舉按 H1 把**槓**放足中點，重心隨身體；不是求解自由度 | 0.0（平衡條件求解） |

兩項觀察：

1. **「小腿角不變」只在深蹲族（4 個清單項目）造成不自然**：股骨相對長的人，現行模型讓他同時軀幹傾得更多、踝背屈一點不增，與「股骨相對長者同時增加踝背屈與軀幹前傾」的教練直覺（及下節 Demers 的方向）不符。硬舉／RDL／早安的小腿角由幾何求出，已隨骨長微調。
2. **極端比例會讓高腳杯在行程中段不可行**：長股骨＋短軀幹＋短小腿（各 1 SD）的組合，高腳杯 `e = 0.75` 軀幹被推到 85° 上限並回報「重心無法維持在腳掌中段」（`pose.ok = false`）。原因同上：只有軀幹可以吸收。這解釋診斷表中高腳杯軀幹角 SD 在 `e = 0.75` 異常大（14.0°）。

## 4. 設計方案

記號：小腿前傾角 θ（= 踝背屈，平底足）、軀幹前傾角 φ；大腿角（深度事件）γ 與平衡條件（系統重心＝現行目標）在所有方案中都不放寬。現行模型 = θ 固定為 θ_ref(P, e)（P = 站距、dom、槓位等），φ 由平衡解出。

### 方案 A：參考策略為錨、平衡約束下分配小腿與軀幹

對每個身體 b、參數 P、行程點 e：

1. 以**預設 1.75 m 男性**解出現行姿勢，取 θ_ref(P, e)、φ_ref(P, e)。
2. 對身體 b 求偏移 Δθ，使

   minimize　J(Δθ) = λ²·Δθ² + (φ_b(Δθ) − φ_ref)²

   subject to　φ_b(Δθ) 由「系統重心 = 現行平衡目標」解出（大腿角 γ 不變，所以髖—膝—踝深度事件相同、壓力中心相同）；θ_ref + Δθ ≤ θ_max（個人踝背屈上限，預設不限）；φ_b ≤ 85°。

λ = σφ/σθ：小腿偏離 1° 與軀幹偏離 λ° 的代價相同。λ→∞ 就是現行模型（軀幹吸收全部）；λ→0 是軀幹角不變、小腿吸收全部（受上限限制）。參考身體：J = 0、Δθ = 0，姿勢逐位元相同（實作要在身體與預設逐值相等時短路，不靠數值最佳化的殘差）。

求解：φ_b(Δθ) 近似線性，割線法 3–4 次內收斂；原型 `analyze` 由 0.64 → 1.19 ms／姿勢。

**性質與界線**：這是「對換算方式敏感的一致性檢查，不是獨立驗證」。Demers 圖讀六點本來就是校準資料，再用它檢查同一個策略沒有獨立性。六點是否都在 ±2° 內取決於外觀標記長度怎麼換成模型關節中心長度：ANSUR 映射 6/6，外觀標記長度直接用 2/6，半途映射 4/6（一點在 −2.0° 邊界）。ANSUR 映射下的 Demers 平均身體（Lt 0.432、Ls 0.378、Ltr 0.520 m）幾乎就是預設身體（0.440、0.394、0.518 m），所以 6/6 主要確認方案 A 讓近預設身體的姿勢維持不變，不是證明方案預測了 Demers 的個體差異。`bodyFromRow` 的係數（預設骨架長度／ANSUR 男性平均標記長度）是假設的每節段固定比例，**不是量測的幾何換算**（關節中心與外觀標記之間沒有逐人影像驗證）。**先後順序要說清楚**：我們是在看到舊映射下 2/6 的結果之後才把映射對齊的；對齊的原則理由是其他研究自 1b21e4c 起都用 `bodyFromRow`，Demers 區塊是唯一不一致的一段，但這個選擇不是在不知道結果的情況下事先訂的。校準值（圖讀點、dom、站距係數、行程指數）沒有改，舊映射的結果另存於 `validation/population-results.json` 的 `demersRawLandmark`。

### 方案 C：以 Demers 相關推導的迴歸偏移

Δθ = k·(Lt/Ls − (Lt/Ls)_ref)（可加軀幹／大腿比項），k 取自 Demers 的 r 與 SD。優點：實作最簡單（不用巢狀求解）、參考身體不變。缺點：k 的出處只有 r（無 SD_DF、無斜率；n = 32），Demers 中站距顯著而寬站不顯著，k 應隨站距變，無依據；不受平衡約束，Δθ 與求出的 φ 不守恆（需要再解 φ，結果仍是平衡的，但沒有「整體分配」的物理意義）；對極端比例（高腳杯不可行案例）沒有保證。實際上等於把方案 A 的結果線性化並且丟掉其約束，不增加證據。

### 方案 D（極端）：軀幹角固定、小腿吸收全部（A 的 λ→0）

長股骨＋短軀幹＋短小腿組合的高槓底點小腿角升到 38.8°（比參考 +6.0°），軀幹不變。上限未知時小腿角無界，過度反應（骨長 ±1 SD 即 ±4–6°，已超過 Demers 暗示的 0–2.7°），不採用；但作為 A 的敏感度上限列出。

### 方案 E：維持現狀並在介面註明

零風險，但問題原樣：小腿角完全不隨骨長，且高腳杯極端比例不可行。

## 5. 推薦：方案 A（λ = 1，個人踝上限可選）

理由：（1）唯一同時滿足「預設姿勢不變」「方向與非測試組證據一致」「平衡與深度事件不放寬」；（2）λ 是明確的、可敏感度掃描的單一假設（與既有 `HEEL_SHANK_SHARE = 0.5` 同層級的示範假設），而不是隱藏在擬合裡；（3）對方案 B 的反證顯示「最小化關節需求」沒有出處且方向相反；（4）把現行模型當作 λ→∞ 的特例，退路清楚。

**預期影響（原型實測，`λ = 1`，不含 θ_max；原型位於暫存目錄，未提交）**

- 參考 1.75 m 男：`node tests/regress.mjs` **IDENTICAL**；`tools/validate-sim.mjs` 的 `validation/results.json` **逐位元相同**（固定身體 13/14 不變）。
- 跑 `tests/body-population.mjs`、`technique-postures.mjs`、`plausibility.mjs`、`trends.mjs --check`：PASS（63 項 × 21 點 × 三種身材全部可行）。
- 群體驗證（`tools/validate-population.mjs`，固定種子 200 人）：全體 27/69 → 26/69；深蹲三篇 8/14 → 7/14，唯一翻轉為 Larsen 2021 低槓窄站軀幹（群體平均 54.38° → 53.96°，研究 56.7 ± 2.5°，門檻約 54.2°；邊界翻轉）。其餘比較項的平均變動：軀幹 ≤ 0.7°、Goršič／Gullett 力矩 ≤ 0.01（Nm/(kg·m)、Nm/kg）；Hutchison 探索項髖 −7.6、膝 +4.3 Nm。模型群體軀幹角 SD 由約 4.6–7.3° 降為 2.1–2.5°，小腿（踝）角由 0° 增為 2.2–2.9°：「吸收」重新分配，總變異未增。這些結果**只用於預告階段 2 的文件更新，不得用於調 λ**；真實受試者的軀幹角變異另有技術選擇等本模型沒有的來源，模型 SD 偏小是預期的。

**風險與未解**

- λ 無出處且文獻無法識別（§4）；若日後取得非測試組、同時報節段長度與負重蹲姿的資料，應回頭用它識別。
- 「軀幹角偏好以預設男性為錨」是假設；女性或矮／高個子亦錨定男性預設的絕對軀幹角（足長、槓位等固定公尺值使等比例身材仍有差異）。
- 小腿角增大可能使膝前移增加、膝力矩上升，教學上要與「踝活動度不足請墊跟」的訊息一併呈現。
- 不模擬個人活動度：θ_max 預設不限，不要宣稱預測個人姿勢。
