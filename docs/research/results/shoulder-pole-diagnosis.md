## 座標核對

令 `t=shElev`、`φ=shPlane`、`c=cosφ`、`s=sinφ`，正交軸是 `e_elev=(-c,0,s)`、`e_hadd=(-cos(t)s,-sin(t),-cos(t)c)`、`e_long=(sin(t)s,-cos(t),sin(t)c)`。上臂方向仍按原旋轉向量求解。原廣義軸與正交軸的關係為

`axis_shFwd = c e_elev + s sinc(t) e_hadd`；`axis_shSide = s e_elev − c sinc(t) e_hadd`，其中 `sinc(t)=sin(t)/t`。同一轉換用於外力矩與肌肉力臂。`t→180°` 時第二方向的尺度趨近零，矩陣條件數為 `1/|sinc(t)|`；這是旋轉向量座標的奇異點。當 `sin(t)≠0` 且方程精確求解時，兩組雙軸平衡代數上等價；接近極點的數值正則項則不具座標不變性。

## 修正後判讀

正握引體底點的水平內收方向仍有 **16.559 N·m** 需求；後三角肌該方向力臂為 **−9.21 mm**，背闊肌只有 **−1.50 mm**。廣義 `shFwd` 中後三角肌的 **−0.61 mm** 確實主要來自座標壓縮，但轉到正交軸後，物理需求也同步放大。正交平衡後該點後三角肌活化為 **2.2853**（修正前 **2.2773**），上舉與水平內收平衡殘差均小於 0.001 N·m。因此座標奇異性是真實的數值設計缺陷，卻不是此高活化的主因。現有負荷、力臂及有效肌力未以同條件量測校準；不能以調整正則項或截斷力臂掩蓋超載。完整變化見[63 項稽核](shoulder-pole-audit.md)。
