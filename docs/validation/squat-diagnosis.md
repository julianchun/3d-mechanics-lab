## 槓位與未處理項目

現程式槓位由軀幹局部座標 `Lb` 與 `ob` 指定，再以全身重心對齊 `cop.z≈0` 求軀幹角。背蹲股骨 70° 時槓到髖水平距離 40.4 cm、到 L5 36.3 cm；前蹲為 40.3／37.2 cm。[Goršič 等研究摘要](https://pubmed.ncbi.nlm.nih.gov/33161870/)確認前後負重位置與軀幹、骨盆調整有關，但沒有提供這兩個定點的槓到髖／腰椎水平距離；無法直接比對，也不能以該研究反設 `Lb`／`ob`。

骨盆分段需要骨盆角、腰椎角、節段質心與力矩作用點一致的資料。現有 [深蹲腰椎／薦骨研究](https://pubmed.ncbi.nlm.nih.gov/20885195/)指出站距與性別均影響角度及時序，[深度與時間研究](https://www.jssm.org/volume19/iss3/cap/jssm-19-500.pdf)也指出各關節峰值時點不同；尚不足以給本模型單一通用的腰骨盆節律常數。壓力中心前後移動也缺與本定點、槓位、鞋跟一致的獨立量測，暫不更動。
