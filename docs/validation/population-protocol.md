# T19 群體模擬：預先固定的比對規則

本文件在執行群體模擬前提交。四篇 `validation/` 研究只作測試組，不用來設定身體節段比例、節段質量或姿勢常數。Demers 2018 只作校準結果的診斷性重算，不重新擬合。

## 抽樣與條件

- 每篇研究使用固定亂數種子，抽樣 **200 個**虛擬人。200 人足以讓群體均值的蒙地卡羅誤差約為模型標準差的 0.071 倍，同時讓每個條件的 400 點峰值掃描可在一般電腦上完成。各條件共用同一組虛擬人，以便比較槓位與站距。
- 男女比例、身高及體重平均與標準差取各研究 `participants`。男女數按原樣比例分配。研究只報全體身高、體重分布時，兩性均使用同一組全體邊際分布；這會低估性別條件差異，不能聲稱為研究的個體資料。身高、體重以截斷常態抽樣；研究未報相關性，因此不假裝知道兩者的相關係數。
- 骨頭比例取 [美國陸軍 ANSUR II 2012 人體測量原始資料](https://ph.health.mil/topics/workplacehealth/ergo/Pages/Anthropometric-Database.aspx)，按性別從同一受試者整列重抽樣，保留可觀測的節段比例相關性。以身高縮放到虛擬人身高。外觀標記點到關節中心的近似方法與不可觀測項另列於實作報告。ANSUR II 是軍人樣本，不能代表四篇研究的訓練者。
- 負重、深度、槓位、站距、鞋跟與事件定義沿用 `validation/*.json` 的現有條件。負重比例乘各虛擬人的體重。負重未知者維持既有探索性設定，不推測公斤數。

## 判定

對原先標為 `comparable` 的每一筆，設研究平均為 μᵣ、研究個體標準差為 sᵣ、模型群體平均為 μₘ：

> **通過當且僅當 |μₘ − μᵣ| ≤ sᵣ。**

理由：研究的個體標準差是事前可讀到的自然變異尺度。模型群體標準差單獨報告，不加入容許範圍，避免模型輸出越分散越容易通過。這是描述性一致性準則，**不是**均值等價檢定或顯著性檢定。研究樣本數只有 10–18，且有未對齊的訓練史與動態條件；不把標準誤誤當個體差異。其餘 `definition-mismatch`、`exploratory`、`consistency-check` 照舊呈現，但不納入通過率。舊的固定 75 kg／1.75 m 模型值與人為絕對容許範圍判定保留並列。

## 可重現性

工具應固定種子、輸出抽樣方法與來源、每筆模型平均 ± 個體標準差、研究平均 ± 個體標準差、舊值／舊判定及新判定。不得因結果好壞更改上述門檻或測試組條件。
